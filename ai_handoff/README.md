# BalanceBot AI 팀장 전달 자료

이 폴더는 다른 AI 에이전트에게 RL-Robust-BalanceBot의 확정 설계와 팀장·서브에이전트 운영 방식을 전달하기 위한 자료다.

- `project_design/`: 현재까지의 프로젝트 목표·요구사항·설계 스냅샷
- `orchestra.md`: 팀장, 역할별 에이전트, 의존성, 검증 규칙
- `system_architecture.md`: 재사용 설계 도구의 시스템 구조 참고
- `team_lead_prompt.md`: 다른 AI 에이전트에 그대로 붙여 넣을 프롬프트

문서의 `confirmed`, `proposed`, `open` 상태를 구분하고, 아직 실행하지 않은 시뮬레이션·성능·영상 결과를 성공으로 표현하지 않는다.
