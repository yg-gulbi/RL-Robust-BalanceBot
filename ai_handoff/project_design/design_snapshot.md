# 현재 설계 보드

단계: 다리 조절의 초기 검증 조건

다리 제어 모드는 키로 명시적으로 전환하도록 정했습니다. 사용자 목표 지정 모드는 자동 모드로 바꾸기 전까지 유지합니다. 전환 시 목표값 처리와 키 배치는 미정이며, 다음으로 다리 조절을 처음 검증할 조건을 정하겠습니다.

## 구성과 동작

- **RL-Robust-BalanceBot** (확정): 두 바퀴·다리 결합 로봇의 시뮬레이션 구현 목표입니다. 로봇 모델을 함께 새로 설계하며 기술 구성은 미정입니다.
- **두 바퀴·다리 결합 로봇** (확정): 능동 다관절 다리를 갖춘 두 바퀴 로봇 모델을 새로 설계합니다. 다리 형상, 관절 수, 링크 배치, 치수와 질량은 미정입니다.
- **능동 다관절 다리로 바퀴·몸체 연결** (확정): 바퀴와 몸체 사이에 구동 가능한 다관절 다리를 둡니다. 몸체 높이와 몸체 기준 바퀴의 앞뒤 위치를 조절하며, 구체적인 연결 형상과 구동기 사양은 미정입니다.
- **몸체 높이·바퀴 앞뒤 위치 조절** (확정): 능동 다관절 다리로 몸체 높이와 몸체 기준 바퀴의 앞뒤 위치를 함께 조절합니다. 가동 범위, 조절 속도와 관절 수는 미정입니다.
- **다리 자동 조절 + 사용자 목표 지정** (확정): 다리 자동 조절과 사용자가 키보드로 지정한 몸체 높이·바퀴 위치 목표값의 추종을 모두 지원합니다. 두 모드는 키로 명시적으로 전환합니다. 제어 알고리즘과 센서 활용은 미정입니다.
- **키로 다리 제어 모드 전환** (확정): 자동 조절 모드와 사용자 목표 지정 모드를 키로 명시적으로 전환합니다. 사용자 지정 모드는 자동 모드로 바꾸기 전까지 유지합니다. 전환 키와 전환 시 목표값 처리는 미정입니다.
- **다리 조절의 초기 검증 조건** (미정): 다리 높이·바퀴 위치 조절과 모드 전환을 제자리 균형 상태부터 검증할지, 저속 평지 주행 중부터 검증할지 미정입니다. 상세 시험 조건과 성공 기준도 미정입니다.
- **스케이트파크 환경** (확정): 평지, 경사, 완만한 요철, 거친 노면과 도약용 램프를 포함합니다. 계단 주행 시험은 제외합니다. 지형 구성과 치수는 미정입니다.
- **키보드 조작 + 자동 시험 명령** (확정): 속도·회전 명령의 키보드 직접 조작과 미리 정한 명령의 자동 재생을 지원합니다. 키보드로 다리 목표값을 지정하고 다리 제어 모드를 전환합니다. 주행 입력 모드 전환과 다리 목표값의 자동 시험 재생 여부는 미정입니다.
- **키보드 직접 조작·다리 목표 지정** (확정): 사용자가 키보드로 속도·회전 명령과 몸체 높이·바퀴 위치 목표값을 지정하고 다리 제어 모드를 전환합니다. 키 배치, 명령 증감 방식과 키를 놓았을 때의 목표값 처리는 미정입니다. 키를 놓는 것만으로 다리 자동 모드에 복귀하지 않습니다.
- **시험 명령 자동 재생** (확정): 미리 정한 속도·회전 명령을 재생해 반복 시험하고 지표를 비교합니다. 시험 명령의 수치, 반복 횟수와 초기 조건은 미정입니다. 다리 목표값 재생의 포함 여부도 미정입니다.
- **1. 평지 균형 주행** (확정): 제자리 균형 → 전진·후진·정지 → 방향 전환 → 외부 충격 후 회복 순으로 검증합니다. 점진적·급격한 명령 변화 모두 성공 범위에 포함합니다.
- **① 제자리 균형** (확정): 제자리에서 균형 유지를 검증합니다. 유지 시간과 허용 오차는 미정입니다.
- **② 전진·후진·정지** (확정): 전진과 후진, 정지에서 균형을 검증합니다. 점진적·급격한 명령 변화 모두 시험합니다. 목표 속도 범위와 정지 오차는 미정입니다.
- **③ 좌우 회전·이동 중 방향 전환** (확정): 좌우 회전과 이동 속도·회전 동시 명령에서 균형을 검증합니다. 회전 속도 범위와 방향 추종 기준은 미정입니다.
- **④ 외부 충격 후 회복** (확정): 외부 충격 후 균형 회복을 검증합니다. 충격 조건과 회복 시간 기준은 미정입니다.
- **목표 속도에서 균형 안정** (확정): 목표 속도에서 균형이 안정적이어야 합니다. 전진·후진 속도 범위와 허용 오차는 미정입니다.
- **속도 오차** (확정): 실제 속도와 목표 속도의 차이 e_v(t) = v(t) − v_ref(t)를 평가 신호로 사용합니다.
- **목표 기울기 대비 앞뒤 기울기 오차** (확정): e_θ(t) = θ(t) − θ_ref(t)를 평가 신호로 사용합니다. θ_ref(t)는 제어 시 생성하는 목표 기울기이며, 생성 방식은 미정입니다.
- **두 오차의 절댓값 적분** (확정): 각 평가 구간에서 J_v = ∫|v(t) − v_ref(t)|dt와 J_θ = ∫|θ(t) − θ_ref(t)|dt를 계산하고 각각 판정합니다. 구간 길이와 임계값 수치는 미정입니다.
- **전후진·회전·동시 명령 안정성** (확정): 전진·후진·정지, 좌우 회전과 이동 속도·회전 동시 명령을 모두 시험합니다. 명령 크기·변화율·유지 시간·반복 횟수는 미정입니다.
- **명령 시험 A. 점진적 변화** (확정): 목표 속도와 회전 명령을 점진적으로 바꾸는 조건부터 검증합니다. 변화율과 명령 범위는 미정입니다.
- **명령 시험 B. 급격한 변화** (확정): 점진적 변화 검증 이후 명령값이 급격히 바뀌는 조건을 검증합니다. 변화 폭과 간격은 미정입니다.
- **평지 안정성 판정** (확정): J_v와 J_θ 모두 각자의 임계값 이내여야 통과합니다. 점진적·급격한 명령 변화 모두에서 균형 안정성을 검증합니다. 구간 분리 방식은 설계안이며 수치 기준과 실행 결과는 없습니다.
- **과도응답·안정 주행 구간 분리** (제안): 위임에 따라 선정한 설계안입니다. 명령 변경·충격 직후 구간과 이후 안정 주행 구간을 나누어 평가합니다. 경계 시점과 구간 길이는 미정입니다.
- **과도응답 평가** (제안): 명령 변경 또는 충격 직후부터 정해진 구간 동안 두 오차를 절댓값 적분합니다. 회복 과정의 오차를 평가하며 구간별 임계값을 둡니다. 수치는 미정입니다.
- **안정 주행 평가** (제안): 과도응답 구간 이후 별도 구간에서 두 적분값을 새로 계산합니다. 구간 도달만으로 회복 성공을 간주하지 않고 지표를 판정합니다. 구간 길이와 임계값은 미정입니다.
- **2. 경사 주행** (확정): 평지 다음에 경사에서 주행을 검증합니다. 경사도와 주행 조건은 미정입니다.
- **3. 울퉁불퉁한 길 주행** (확정): 완만한 요철부터 불규칙한 돌출부·패임이 있는 거친 노면까지 검증합니다. 높이, 간격과 난도는 미정입니다.
- **지형 A. 완만한 요철** (확정): 노면이 부드럽게 오르내리는 길에서 균형 주행을 먼저 검증합니다. 요철 높이와 간격은 미정입니다.
- **지형 B. 거친 노면** (확정): 완만한 요철 다음에 불규칙한 돌출부·패임이 있는 노면에서 주행을 검증합니다. 형상, 높이와 분포는 미정입니다.
- **4. 램프 도약** (확정): 울퉁불퉁한 길 주행 단계 다음에 주행 속도와 램프 형상을 이용한 도약을 검증합니다. 자체 도약 동작은 이번 점프 요구에 포함하지 않습니다. 램프 형상, 진입 속도와 공중 자세는 미정입니다.
- **착지 후 균형 회복·안정화** (확정): 램프 도약·낙하 후 착지 상태에서 균형을 회복합니다. 완전히 넘어진 뒤 자동 기립은 이번 복구 범위에 포함하지 않습니다. 착지 조건과 안정화 판정 기준은 미정입니다.
- **균형 주행** (확정): 각 주행 단계에서 균형을 유지하며 이동하는 공통 목표입니다. 다리는 몸체 높이·바퀴 위치의 자동 조절과 사용자 목표값 추종을 지원합니다. 바퀴와 다리의 제어 분담 및 지형별 성능 기준은 미정입니다.
- **험지 통과** (확정): 경사와 완만한 요철·거친 노면에서 주행을 검증합니다. 계단 주행은 제외했습니다. 단계별 성공 기준은 미정입니다.
- **뎁스카메라·라이다 장착** (확정): 두 센서를 시뮬레이션 로봇에 장착합니다. 센서 융합·내비게이션 활용은 현재 필수 요구에 포함하지 않습니다. 장착 위치와 센서 구성은 미정입니다.
- **설계 시각화·실제 동작 영상** (확정): 설계 시각화와 실제 시뮬레이션 동작 영상을 산출물로 만듭니다. 콘셉트 영상은 실제 시뮬레이션이나 학습 결과로 취급하지 않습니다. 실행 결과는 아직 검증되지 않았습니다.

- manual-control → leg-mode-switch: 키로 모드 선택
- leg-mode-switch → leg-control: 명시적 전환·선택 모드 유지
- leg-control → leg-validation: 두 제어 방식의 검증 조건 구체화
- leg-mode-switch → leg-validation: 모드 전환 검증 조건 구체화

- robot → skatepark: 전체 시뮬레이션 환경
- robot → command-input: 두 가지 명령 입력 방식
- manual-control → command-input: 키보드 조작 명령

- first-milestone → gradual-command: 명령 변화 조건의 검증 순서
- gradual-command → abrupt-command: 다음 명령 변화 조건
- gradual-command → command-stability: 성공 범위에 포함

## 결정

- **복구 범위 확정** (확정): 이번 복구 범위는 착지 후 균형 회복입니다. 완전히 넘어진 뒤 자동 기립은 포함하지 않습니다. 낙하 조건과 회복 판정 기준은 미정입니다.
- **두 바퀴·다리 결합 형태로 변경** (확정): 두 바퀴에 능동 다관절 다리를 결합한 형태로 설계합니다. 다리 형상과 관절 수는 아직 정하지 않았습니다.
- **환경과 검증 순서 확정** (확정): 전체 환경은 스케이트파크입니다. 평지 → 경사 → 완만한 요철 → 거친 노면 → 램프 도약·착지·안정화 순으로 검증합니다. 계단 단계는 제외했습니다. 지형별 성공 기준은 미정입니다.
